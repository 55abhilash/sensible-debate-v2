# Pinned to exact versions that are tested together. uvicorn's WebSocket
# support and the `websockets` package version are tightly coupled - an
# uvicorn/websockets mismatch is the single most common install problem
# with this kind of app (it shows up as an ImportError mentioning
# ServerProtocol/ServerConnection at startup). Pinning both here means
# `pip install -r requirements.txt` always gets a matched pair, even if
# something else on your machine already has a different websockets
# version installed. See DEPLOYMENT.md / README.md if you ever need to
# deliberately upgrade these.
